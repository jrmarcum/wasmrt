# wazmrt C-ABI Map (for the 1:1 Rust port)

Source files: `src/wasm_c_api.zig` (2872 L), `third_party/wasm-c-api/include/wasm.h`,
`include/wazmrt.h`, `tests/c_abi_symbols.c`, `tests/c_smoke.c`, `src/root.zig`, `src/wasm_entry.zig`.
Allocator: `builtin.is_test ? std.testing.allocator : std.heap.smp_allocator` (comptime-selected).

## 1. Refcounted object model
One `RefHeader` (= `wasm_ref_t`) embedded by every ref-able object:
```
tag: RefTag(enum u8 { extern_obj, foreign, instance, module, trap })
rc: u32 = 1
host_info: ?*anyopaque = null
host_info_finalizer: ?fn(?*anyopaque) callconv(.c) void = null
```
- retain: rc+=1. release: rc==0 → false (idempotent double-delete guard); else rc-=1; at 0 run
  finalizer, return true. Refcount driven to 0, not left at 1 — second delete is a no-op.
- Upcast (X_as_ref) = borrowed &obj.hdr (must not alloc). Downcast (ref_as_X) =
  @fieldParentPtr("hdr",h) + tag/kind check. Do NOT assume hdr at offset 0.

5 concrete structs embed RefHeader (all begin with hdr):
| Struct | tag | extra |
| Module | module | inner: root.Module; bytes: []u8 (owned original binary, kept for serialize) |
| Foreign | foreign | header only (host_info is the point) |
| Instance | instance | inst: root.Instance; host_funcs: []HostFunc (owned, borrowed by inst); module: *Module (retained) |
| Trap | trap | message: ByteVec (NUL-term); frames: []Frame (snapshotted) |
| Ref | extern_obj | backs all 5 extern kinds: kind: Externkind; vec_owned: bool; instance: ?*Instance; index: u32; host: ?HostCallback; functype: ?*FuncType; host_global/_memory/_table |

`Ref` = one struct for func/global/table/memory extern; kind discriminates. Two flavors:
export handle (instance+index; cheap view) or standalone host object (host_*/host set,
instance==null, from wasm_*_new).

**copy = reference, not clone** for ref-able objects: wasm_X_copy = retain, returns same pointer,
same(copy,x)==true. EXCEPTION: export handle with vec_owned==true is *duplicated* (dupExportHandle:
new Ref same kind+instance+index, refRetainInstance) — else the owning extern_vec frees a pointer
you still hold (UAF). `same` for extern handles = structural: instance!=null && instance==other.instance
&& kind==other.kind && index==other.index.

**Type/value objects are deep-cloned values, NOT refs** (copy allocates distinct object,
content(copy)!=content(orig)): ValType{kind:u8}, FuncType, GlobalType, TableType, MemoryType,
TagType, ImportType, ExportType, Frame. No RefHeader/refcount/host_info. copyExternType recurses;
wasm_val_copy = plain struct copy.

host_info+finalizer on RefHeader; finalizer runs once when LAST handle released; survives copy.
Checked casts: ref_as_X → null on tag mismatch (+ Ref.kind mismatch for extern sub-kinds);
externtype_as_X reads first byte ekind, null on mismatch.

## 2. Ownership / lifetime / memory-safety
Two hard rules:
1. Every free of a Ref goes through refDelete (never alloc.destroy) — destroyRef is the ONLY place
   Ref storage is released; it drops instance handle, runs finalizer, frees functype/host_*.
2. Nothing aliases a Ref without owning a handle — copy retains or dups, never repeats the pointer.

Lifetime chains (both were shipped bugs, now test-enforced):
- Instance keeps module alive: instance_new retains &module.hdr, stores module:*Module; instance_delete
  calls module_delete on it. Embedder may delete module right after instantiation.
- Export handle keeps instance alive: every export Ref / dupExportHandle / table-get funcref calls
  refRetainInstance; destroyRef releases via instance_delete. exports(); instance_delete(); func_call() stays valid.

vec ownership:
- instance_exports allocates Refs with vec_owned=true; extern_vec_delete frees each via destroyRef. Don't individually delete.
- extern_vec_new takes ownership of element pointers. extern_vec_delete frees each (vec_owned→destroyRef, standalone→refDelete).
- extern_vec_copy: elements are refs → each takes real handle (retain or dup for export handles). Aliasing = freelist-corrupting double free (regression-tested).
- Type-vec families deep-clone on copy, delete each on delete (generated by VecApi comptime loop; importtype/exporttype hand-written deleters).
- Constructors moving vecs (functype_new, importtype_new, exporttype_new) null out the caller's vec.
- ByteVec/ValVec/ValTypeVec/ExternVec/FrameVec are extern struct {size: usize, data: [*c]…} — exact C layout.

## 4. Trampoline / host-func bridge
wasm_func_new / _with_env → standalone Ref{kind=FUNC, host=HostCallback{plain|with_env,env,finalizer},
functype=copyFuncType(ft)} (owns deep functype copy). Callback: fn(?*const ValVec,?*ValVec) callconv(.c) ?*Trap (+env variant).
Wiring at instance_new: iterate m.inner.imports in wasm_module_imports order → per-kind interp arrays.
Func import w/ host!=null → HostFunc.native_env{ctx=ext, call=hostTrampoline}; unbacked → {ctx=&unbacked_marker,
call=unbackedTrap} (traps only if called). Globals: value copied. Mem/table: borrowed shared objects.
funcs → toOwnedSlice → Instance.host_funcs (borrowed by inst); other arrays freed after init.
hostTrampoline(ctx,args:[]const u64,results:[]u64)→bool: recover ref, read host+functype, build ValVec
typed by functype.params (slotToValKind), alloc uninit result ValVec, call cb (with_env preferred).
Trap returned → wasm_trap_delete(t), return false (→ error.HostTrap). Success → valToSlot back, true.
wasm_func_call: standalone host → call cb directly. Export handle → valToSlot args, inst.invokeIndex(index,argv);
error → makeTrapFrom(@errorName(e),wi) (snapshots trace before next call resets it); success → slotToVal
up to min(out.size,res.len,ft.results.len) typed by validated result valtypes.
Trap.message NUL-term copy; Trap.frames snapshotted; Frame{instance,func_index,func_offset(body byte),
module_offset(binary byte)} resolved lazily via inst.frameOffset. trap_origin=frames[0], trap_trace=full
innermost-first (owned clones). Host-cb traps carry no frames.

## 5. Allocator — single comptime alloc; testing.allocator under `zig build test` (catches df/leak/uaf),
smp_allocator otherwise; libc-free (also targets wasm32-freestanding → wasm_allocator). All deletes route
through destroyRef/refDelete/release choke points. Rust: thread one allocator/global identically; don't assume libc malloc.

## 6. Zig idioms → Rust
- extern struct C-layout (ByteVec, Val/ValOf union offset-8, vecs, Limits, *Type with ekind first) → #[repr(C)];
  ekind-first makes X_as_externtype a ptr cast + externtype_kind a first-byte read → leading u8 discriminant.
- @fieldParentPtr("hdr",h) → container_of/offset_of!; do NOT assume offset 0.
- @ptrCast/@alignCast, *anyopaque → raw ptr casts + alignment care; opaque C ptr = *mut c_void.
- [*c] (nullable C ptr) / ?*T → *mut T / Option<&mut T>; null-check everywhere (orelse return).
- Tagged unions (RefTag, interp.HostFunc union(enum)) → Rust enums. rc is plain u32 NOT atomic
  (single-threaded) — match with Cell<u32>, do NOT upgrade to Arc.
- comptime @export loops (ref surface, type-vec surface) → macro_rules! or build script; exact symbol names (link gate).
- callconv(.c) → extern "C" on all exported fns + callback fn-ptr types.
- Pointer-width: interp Value=u64; refs cross as @intFromPtr/@ptrFromInt — real host ptr in u64 slot, never
  truncated to i32. wasm_val_ptr/init_ptr branch on UINTPTR_MAX. Use usize/u64/*mut c_void, not hardcoded i32.
