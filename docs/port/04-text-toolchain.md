# wazmrt WAT/WAST text toolchain — Port Map (sexpr/wat/wast)

Files: sexpr.zig (246 L), wat.zig (2726 L), wast.zig (798 L). Peers: opcode.zig (Op/Imm authority), types.zig (ValType), Module.zig, validate.zig, interp.zig (Instance, Value). Arena allocation throughout; List(T)=std.ArrayList(T). Rust: arena→bumpalo or owned Vecs.

## 1. sexpr.zig
AST: Sexpr=union{atom:[]const u8, string:[]const u8, list:[]const Sexpr}. atom=raw source slice for keywords/$identifiers/numbers/key=value (offset=4, align=2) — NO numeric parse here. string=DECODED bytes (escapes resolved) so (module binary "\00asm…") yields real bytes. Helpers keyword()/asAtom()/asList().
Errors: UnexpectedEof, UnexpectedParen, UnterminatedString, UnterminatedList, BadEscape (+alloc).
Entry parseAll(a,src)→[]Sexpr flat vec of top-level forms. Loop skipTrivia then parseValue until EOF.
Lexer Parser{src,pos,a} single forward index recursive-descent over bytes: skipTrivia (spaces/\t\r\n; line comments ;;…\n; NESTABLE block comments (;…;) via depth counter — keep nesting). parseValue dispatch first byte: (→list, )→UnexpectedParen, "→string, else atom. parseList consume ( loop until ); EOF→UnterminatedList. parseAtom until ` \t\r\n()";` (`;` terminates atom → trailing comments). parseString escapes \t\n\r\"\'\\ ; \u{...}→UTF-8; else two-hex \XX→byte; bad/short→BadEscape; missing close→UnterminatedString.
NO line/col tracking — error values only. Rust: Result<_,SexprError>.

## 2. wat.zig — WAT text → wasm binary (inverse of Module.decode)
Public: assemble(a,src) (first (module…)), assembleModule(a,module:[]Sexpr) (module[0]=="module"). Output full binary (magic 00 61 73 6d 01 00 00 00 + sections).
### 2.1 Name→Op: lookupOp(name) copy into [64]u8, replace .→_, std.meta.stringToEnum(Op,buf). i32.add→i32_add. SINGLE SOURCE of instr identity (reuses opcode.zig Op). Rust: generated &str→Op (phf/match) on underscore form; Zig @"if"/@"return"/@"else" keywords.
CRITICAL emit: Op enum(u8) values are INTERNAL tags NOT wire bytes for prefixed ops. emitOpcode(op): fcSubOpcode(op) non-null→0xFC+ULEB(sub) (trunc_sat, memory.init/copy/fill, data.drop, table.init/drop/copy/grow/size/fill); gcSubOpcode(op) non-null→0xFB+ULEB(sub) (struct.*, array.*, ref.test/cast null-form-at-emit, br_on_cast[_fail], ref.i31, i31.get_s/u); else single byte @intFromEnum(op). immediateKind(op)→ImmKind emitter switches on; flatImmCount(op) derives flat atoms.
### 2.2 assembleModule multi-pass (order matters): Pre-pass A scan (type…) names incl inside (rec…) (flattened, emitted ungrouped) → type_names+type_forms (names before bodies for forward (ref $t)). Pre-pass B parseTypeBody→sigs, gc_types (func/struct/array), gc_supers (index-aligned w/ type_names). Pass 1 walk fields by keyword (func/export/global/memory/data/table/elem/import/start), build parallel index-space name arrays (func_names/table_names/global_names/elem_names)+def lists. Type resolution & body pre-encode: assign func type indices ((type $t) via resolveType else internSig inline), encodeBody each func. Const-expr sections (global/element/data) pre-encoded BEFORE type section serialized so interned sigs land in section 1. Serialize sections 1-11.
Import-ordering: fieldIsImport/isDefKind/seen_definition — import after any func/table/memory/global DEFINITION → error.ImportAfterDefinition (§6.6.13). Track this flag.
### 2.3 Symbol table = LINEAR SCAN of parallel []?[]const u8 name arrays, index==wasm index-space slot, anon=null. resolveByName(names,s): atom starts $ → linear search equal → index else UnknownIdentifier; numeric → parseIndex (parseInt(u32,atom,0) base auto). resolveType/resolveLocal/resolveFunc same over type_names/local_names/func_names. Index-space invariant: imports low indices, name arrays appended import-then-def per space. Locals: local_names=params-then-locals index-aligned null anon; parseDecls handles (param $x i32) + (param i32 i32); a func using (type $t) with no inline params PREPENDS N anon names so declared-local $name indices stay correct. Labels: Ctx.labels:List(?[]const u8) innermost last; resolveLabel $name→relative depth len-1-k, numeric literal; pushed/popped around block/loop/if.
### 2.4 Instruction emission (folded+flat): Ctx carries out/local_names/func_names/sigs/type_names/global_names/table_names/elem_names/labels. emitSeq→emitOne (list→emitFoldedOne, atom→emitFlatOne, string→error). Folded (op imm* operand*): consume leading atom immediates, recursively emit operand sub-lists, THEN opcode+immediates (post-order, operands first = stack order). Special folded heads: block/loop (emitFoldedBlock), if (emitFoldedIf, optional folded cond before (then…), optional (else…)), select, call_indirect, ref.test/cast, br_on_cast/_fail. Flat emitFlatOne: block/loop/if push label+blocktype+return j; else/end emit+pop; br_table gather trailing atoms; select gather (result…); call_indirect; ref-cast; table ops (optional explicit idx); bulk (table.init/elem.drop/table.copy gather 0-2 idx). Default: mem kind consume only offset=/align= atoms; else exactly flatImmCount(op) atoms.
### 2.5 Control flow/labels/blocktypes: parseOptLabel leading $…. parseBlockTypeSig→BlockTy{type_ref:?u32,sig} from (type $t) and/or (param)(result). emitBlockTypeSig: type_ref→SLEB(index); empty→0x40; single NON-concrete result→value-type byte; params-or-multi-result→SLEB(internSig). Concrete ref result CANNOT use single-byte (0x63/0x64 ti misread as s33) → forced internSig.
### 2.6 memarg: emitMemArg defaults offset=0, align_log2=naturalAlign(op). Parse offset=(u64), align=(bytes). Alignment must be NONZERO POWER OF TWO else BadImmediate. Emit ULEB(align_log2) then ULEB(offset).
### 2.7 Memory+data: (memory $name? (export)* (import)|(data "…")|min[max]). (memory (data…)) sizes to ceil(bytes/64K) pages + synthetic active data seg offset 0. (data $id? (memory idx)? offset? "bytes"): offset=leading list (kept even if malformed→validator rejects); absent→PASSIVE. encodeDataSection flag 0x00 active mem0 + offset-expr or 0x01 passive; ULEB(len)+bytes. Only mem 0.
### 2.8 Globals: parseGlobal $name?, (export)*, optional (import "m" "n"), type (valtype or (mut valtype) — list may be mut wrapper OR (ref…)), init=ALL remaining forms (sequence; missing→bare end→validator rejects). Imported→global_imports; defined→globals. encodeGlobalSection valtype+mut+emitConstExpr. Extended-const implicit (init full seq via emitSeq). Import global 0x03+valtype+mut.
### 2.9 call_indirect+multi-table: parseCallIndirectType optional explicit table (atom only if followed by (type/param/result) annotation else atom is next instr), (type $t) and/or inline (param)(result); idx=resolveType or internSig. emitCallIndirect opcode+ULEB(type_index)+ULEB(table). Table ops optional $name/numeric operand default 0.
### 2.10 Element (8 flag variants): parseElem/encodeElementSection. Mode from declare(declarative), leading (table $t) and/or offset form (isOffsetForm (offset…)/(i32.const…)/(global.get…))→active else passive. Kind: func keyword (func-index) or reftype (const-expr); absent=abbreviated func-index. Flag bits: bit0 passive/declarative, bit1 declarative-or-explicit-table, bit2 const-expr form. Emit explicit table if bit1-active; offset-expr if active; leading kind byte 0x00 elemkind (non-flag-0 func-idx) or reftype byte (non-flag-4 const-expr); then exprs (emitElementExpr accepts (ref.func $f) or (item <seq>)) or funcs (resolveByName(func_names)). emitOffsetExpr unwraps (offset…), folded const-expr, or synth i32.const 0. Inline (table reftype (elem…)) + (table N reftype initexpr) → N synthetic copies active expr-form.
### 2.11 Reftypes+table reftypes: isRefType funcref/externref/(ref…). parseValType/heapTypeToValType: concrete $t/numeric→V.concreteRef(nullable,.struct,index) (kind bits placeholder — assembler emits only index, decoder re-derives family); abstract heads→family value types; stringToValType shorthand. emitValType concrete→0x64(non-null)/0x63(nullable)+SLEB(index) else single byte. ref.null imm (.ref_type): abstract head code or concrete index SLEB s33. Ref-cast targets abstractHeapCode: any=-0x12 eq=-0x13 i31=-0x14 struct=-0x15 array=-0x16 none=-0x0f func=-0x10 extern=-0x11 nofunc=-0x0d noextern=-0x0e; non-neg=type index. emitRefCast/emitBrCast pick null/non-null sub-opcodes + flags byte (bit0 src-null, bit1 dst-null).
### 2.12 GC composite+supertypes: parseTypeBody unwraps (sub final? $super? <comptype>) capture ≤1 super (finality unused), inner comptype last. (func)→sig+.func; (struct (field)*)→placeholder sig+.struct fields; (array <fieldtype>)→placeholder+.array field. Fields parseFieldGroup/Elem/Storage (mut? storage), storage i8/i16 packed or valtype. Type emit: if super emit 0x50(sub non-final)+ULEB(1)+ULEB(super) BEFORE composite; then 0x60 func / 0x5f struct(count+fields) / 0x5e array(field). emitGcField storage byte (i8=0x78 i16=0x77 else valtype)+mut.
### 2.13 Bulk: emitBulkTableImm table.init text tableidx? elemidx but BINARY elem-then-table; elem.drop 1 elem; table.copy dst,src. Memory bulk memory.init data idx+reserved 0x00; data.drop data idx; memory.copy 00 00; memory.fill 00.
### 2.14 Numeric/NaN: parseWatI32 (i64/u32 truncate sign-ext), parseWatI64, floatLitBits: parseFloat; nan:canonical→f32 0x7fc00000/f64 0x7ff8000000000000; nan:arithmetic→canonical exp/quiet+payload; nan:0x<payload>→canonical exp/quiet + payload mantissa; leading - sets sign. LE raw bits. uleb/sleb (arithmetic-shift signed).

## 3. wast.zig — WAST runner
Pipeline: sexpr.parseAll→moduleBinary (assemble or decode binary)→Module.decode→validate→interp.Instance.initWithImports→runStart→actions→compare. Public runScript(gpa,src)→Summary{passed,failed,skipped,first_failure}. Per-call arena.
Runner state: current:?*Instance, modules (StringHashMap by (register "name")), module_names (StringHashMap by $M), lazy shared spectest memory (1/max2) + table (10/max20 funcref), extern_pool:List(u64) (interned externref payloads), summary. Two hash maps = only real symbol tables in toolchain.
command dispatch by keyword: module→buildModule set current, if (module $M…) record module_names. assert_return/assert_trap/assert_exhaustion/assert_invalid|malformed(→assertRejected)/assert_unlinkable/register/invoke|get→runAction. Unknown (module quote, assert_exception)→skipped++.
buildModule=moduleBinary→decode→validate→initWithImports(resolveImports)→runStart (start trap=instantiation failure). moduleBinary: (module binary "…") concat string bytes; (module quote…)→BadCommand; else wat.assembleModule.
Import linking resolveImports: match each import to REGISTERED module export (in modules) or spectest stub, check declared vs actual type. Unknown→UnresolvedImport; mismatch→IncompatibleImportType (both="unlinkable"). spectest: print* funcs noop, immutable globals global_i32/i64/f32/f64=666/666.6, shared memory/table. funcTypeEq/valTypesEq exact; limitsFit: provided.min>=required.min and (if required bounded) provided bounded<=required.max.
runAction: (invoke $M? "name" args…), (get $M? "name"). actionTarget leading $M→module_names (consumed) else current; unavailable→error.NoTarget (assertions SKIP not falsely fail). invoke parseConst args, inst.invoke. get→getGlobal (scan exports for global, read inst.globals[e.index]).
parseConst: (T.const lit)→i32Value(truncate)/i64Value/f32=parseFloatBits(f32)/f64. ref.null→null_ref(maxInt u64); ref.extern N→interned via internExtern (bare→intern 0); ref.func N→func index (bare→null_ref-1 "any non-null"). Ints parseInt i64 then u64-bitcast fallback.
externref interning (#9): internExtern(payload) linear-scan extern_pool equality else append; stack value=small INDEX never null_ref sentinel — so payload==maxInt(u64) not misread as null, round-trips equal. Preserve indirection.
Assertion semantics (match for parity): assert_return (assertReturn+matches): run action; NoTarget→skip; other error→fail. Arity==expected. matches(got,exp): ref.null→got==null_ref; bare ref.extern/func→got!=null_ref; payload→exact (extern interned, func by index). f32/f64.const→floatMatches: nan:canonical→isCanonicalNan (exp all-ones + mantissa top bit only); nan:arithmetic→isArithmeticNan (exp all-ones + quiet bit); else exact truncated bit compare. ints→exact bit equality.
assert_trap (assertTrap): (module…)→instantiation must trap (build isolated, not recorded); else run action. Pass ONLY if isRuntimeTrap (Unreachable,DivByZero,IntOverflow,InvalidConversionToInt,MemoryOutOfBounds,TableOutOfBounds,UninitializedElement,IndirectTypeMismatch,NullReference,GcOutOfBounds,CastFailure,HostTrap,CallStackExhausted). NoTarget→skip. Engine limits/decode/assemble errors NOT green-washed. Result instead of trap→fail.
assert_exhaustion: exactly error.CallStackExhausted; other→fail; NoTarget→skip.
assert_invalid/malformed (assertRejected→tryBuild=moduleBinary+decode+validate no instantiate): module MUST be rejected; acceptance→fail. (Malformed+invalid collapse to same check — no decode-time vs validate-time distinction.)
assert_unlinkable (assertUnlinkable): valid but must fail LINK; pass only if isLinkError (UnresolvedImport,MissingImport,IncompatibleImportType); decode/validate/runtime error does NOT count.
register "name" $id?: expose $id-named (or current) exports under "name" in modules.
invoke/get bare: run for side effects; error→fail("action failed").
Parity gaps to carry/fix: no line/col; assert_malformed uses same path as assert_invalid; (module quote…) unsupported; GC concrete-ref kind bits placeholders (decoder re-derives). Rust: model isRuntimeTrap/isLinkError as explicit trap/link error enums.
