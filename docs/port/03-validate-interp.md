# wazmrt execution engine — Port Map (validate.zig + interp.zig)

Shared: V=types.ValType, Op=opcode.Op. IR=opcode.Instr{op,imm} from opcode.decodeBody(arena,body). Consumes IR not raw bytes, except const-exprs (re-parsed with Reader).

## PART A — validate.zig (spec §3 Appendix)
### A1 Algorithm — two parallel stacks per function (ArrayList in scratch arena):
vals: ArrayList(StackType) where StackType=union{val:V, unknown} (unknown = spec bottom ⊥ for post-unreachable polymorphic code). ctrls: ArrayList(Frame).
Frame{kind:FrameKind(block|loop|if_|else_), start:[]V, end:[]V, height:usize (vals height at entry), is_unreachable:bool, init_snapshot:[]bool}.
Core ops (mirror appendix exactly): popVal — if vals.len==top.height: .unknown when top.is_unreachable else StackUnderflow; else pop real (THE CRUX: frame height floor makes unreachable frame produce infinite unknowns). popExpect(expect): popVal; .unknown always matches; .val t must subtypeOf(t,expect). popVals(ts) reverse. popRef. push*. pushCtrl(kind,start,end): record height, snapshot local_init (dupe), push start. popCtrl: popVals(end), assert vals.len==frame.height (StackHeightMismatch), pop. setUnreachable: vals.shrinkRetainingCapacity(top.height) then is_unreachable=true. labelTypesAt(n): frame n from top; LOOP→frame.start (branch target=loop header=params), else frame.end.
validateFunction: locals=params++RLE-expanded declared; body wrapped in implicit block []→results; iterate step(instr); require ctrls.len==0 at end (else ControlUnderflow). step guards ctrls.len==0 first.
### A2 Local-init (func-refs §3.3.5): local_init:[]bool. Init if i<n_params or !t.isNonNullRef (non-null ref locals start UNINIT). local_get: t.isNonNullRef && !init && !topUnreachable → UninitializedLocal. set/tee mark init. else: restore from frame.init_snapshot then push else_ frame. end: also restore.
### A3 Control-flow in step: block/loop blockSig→pop params,pushCtrl; if additionally popExpect(i32). blockSig(bt): empty→[],[]; value t→[],[t]; type_index i→funcSig(i) (UndefinedType). else: popCtrl require kind==if_ (MismatchedElse), restore, push else_. end: popCtrl; if kind==if_ require start==end (else-less if implicit identity else → TypeMismatch); restore; push end. br L: popVals(labelTypesAt(L)), setUnreachable. br_if L: popExpect(i32), pop then re-push. br_table: popExpect(i32); each label lt.len==default_lt.len (TypeMismatch), pop+push; popVals(default), setUnreachable. return: popVals(results), setUnreachable.
### A4 Select: untyped — popExpect(i32); pop two; REJECT if either ref (need typed form); unify unknown-aware; push. typed select_t — annotation len exactly 1; popExpect(i32), popExpect(t)×2, push t.
### A5 Module checks (validate, first error wins): 1. functions.len==code.len else CountMismatch. 2. Global inits (defined tail, n_imported=globals.len-global_inits.len) via validateConstExpr(module,expr,type,self_index). 3. Elements: elem.funcs[fi] resolve (funcType!=null else UndefinedFunc); element expr → elem_type, self_index=n_imported_globals (element exprs ref ONLY imported globals — deliberate asymmetry vs offsets); active: table_index<tables.len (UndefinedTable), nullable-family match elem_type.nullable()==tet.nullable() (TypeMismatch); offset expr→i32 self_index=all_globals (offsets ref ANY immutable global). 4. Data active only: mem_index<memories.len (MissingMemory), offset→i32 (all_globals). 5. Start §3.5.5: funcType(si) exists, must be []→[] else InvalidStartFunction. 6. Per fn: funcSig(type_index)(UndefinedType); validateFunction; arena reset(.retain_capacity) between.
### A6 validateConstExpr(module,expr,expected,self_index): fixed [8]V stack (overflow→ConstantExpressionRequired), re-parse bytes via Reader. Accept: 0x41/42/43/44 const; 0x23 global.get x (x<self_index else UndefinedGlobal; !globals[x].mutable else ConstantExpressionRequired; push content); 0xd0 ref.null <heap> (readHeapType, push nullable); 0xd2 ref.func x (funcType exists; concrete (ref $ftype) via funcTypeIndex else funcref_nn); extended-const 0x6a/6b/6c i32 add/sub/mul, 0x7c/7d/7e i64 (pop 1 of top-2). Else ConstantExpressionRequired. End 0x0b: require sp==1 && subtypeOf(stack[0],expected) else TypeMismatch.
### A7 table/mem/ref/GC/bulk in step: tableElemType(i) bounds (UndefinedTable). call_indirect: table exists, element==funcref (TypeMismatch), funcSig(UndefinedType), pop i32 idx+params, push results. table_init: elem valid (UndefinedElem), elements[elem].elem_type==tet. table_copy: dt==st. Bulk mem: copy/fill/init need memories.len>0 (MissingMemory); init/data_drop data idx valid (UndefinedData); pop [dst,src|byte,n] i32. Refs: ref_null push nullable; ref_is_null pop ref→i32; ref_func concrete-or-funcref_nn. Typed func refs: call_ref/return_call_ref funcSig(func), popExpect(funcref), pop params; call_ref push results; return_call_ref requires valTypesEqual(ft.results,self.results) then setUnreachable. ref_as_non_null: pushVal(popRef). br_on_null: popRef, pop/push label, push non-null ref. br_on_non_null: label last funcref/externref, pop/push label, popRef.
### A8 GC in step (P3): ref_i31 pop i32 push i31ref_nn; i31_get_s/u popExpect(i31ref) push i32. ref_eq pop two eqref push i32. struct: structFields(gc_type)(UndefinedType); struct_new pops fields REVERSE (storage.unpacked()), push concreteRef(false,struct,ti); _default requires all defaultable (!isNonNullRef); get[_s/_u] field bounds (UndefinedField), requirePacking, popExpect(structref), push unpacked; set requires mutable (ImmutableField). array: arrayField(gc_type); new/_default/_fixed/_get/_set/_len; requirePacking + mutability. requirePacking(is_plain_get,storage): is_plain_get==isPacked → BadFieldPacking. casts: ref_test popRef→i32; ref_cast popRef→push refTypeValType. br_on_cast/br_on_cast_fail: require subtypeOf(dst,src) (downcast); carried=dst for cast, src for cast_fail, subtype of label last; fall-through pushes src (cast) or dst (cast_fail).
### A9 subtypeOf (port carefully):
  sub==sup→true; !sub.isRef||!sup.isRef→false (numerics equal-only); sup.isNonNullRef && !sub.isNonNullRef→false ((ref t)<:(ref null t) not reverse); sub.isConcrete&&sup.isConcrete→module.isSubtype(sub.ci,sup.ci) (declared chain); sub.isConcrete→sub.refHeap().sub(sup.refHeap()); sup.isConcrete→sub.refHeap()==.none; else sub.refHeap().sub(sup.refHeap()).
  CONCRETE-CONCRETE MUST walk isSubtype — collapsed heads alone wrongly accept any-two-structs.
  refTypeValType(module,rt): head=refHead(rt.heap); concrete→concreteRef(rt.nullable,head,ti); else head.valType(rt.nullable).
### A10 Fallthrough numeric/mem: load/store (immediateKind==.mem) require memory (MissingMemory) and imm.mem.alignment<=naturalAlignLog2(op) else InvalidAlignment (≤ natural, log2 immediate so no explicit pow2 check). Then simpleSig(op) opcode→(pop,push) table else UnsupportedOpcode.
### A11 Error set: Module.Error || {CountMismatch,TypeMismatch,StackUnderflow,StackHeightMismatch,ControlUnderflow,UnknownLabel,MismatchedElse,UndefinedLocal,UninitializedLocal,UndefinedGlobal,ImmutableGlobal,UndefinedFunc,UndefinedType,UndefinedTable,UndefinedElem,UndefinedData,UndefinedField,ImmutableField,BadFieldPacking,InvalidStartFunction,ConstantExpressionRequired,InvalidAlignment,MissingMemory}. Validator doesn't mutate module; decodes bodies to IR in scratch arena.

## PART B — interp.zig
### B1 Value model: Value=u64 UNTYPED slot (validation proved types). i32Value/asI32 (bitcast u32 truncate), i64/f32/f64. page_size=64K.
Sentinel/tag bits (port exactly): null_ref=maxInt(u64) (null on stack + uninit table slot; safe: funcref=small idx, externref=small handle, GC=small idx). i31_tag=1<<63 (unboxed i31; checked AFTER null so null/tagged-i31/heap-index never collide). packField/unpackField for i8/i16 packed (sign/zero-extend).
### B2 Instance layout + lifetime (UAF fix): {gpa, arena, module:*const Module (RETAINED — must outlive instance), func_bodies:[]FuncBody, globals:[]Value, imported_funcs:u32, import_funcs:[]const HostFunc, memory:?*Memory (shared or null), imported_memory:bool (borrowed if true), tables:[]*Table (outer gpa; [0..imported] borrowed), imported_tables:u32, elem_values:[]const []Value, elem_dropped:[]bool, data_dropped:[]bool, trap_frames:[16]TrapFrame, trap_len, trap_depth, gc_heap:ArrayList(HeapObject)}.
HeapObject{type_index:u32 (RTT), fields:[]Value} — one per struct/array; no collector (arena field slices, live for instance). GC ref value = index into gc_heap. Memory{bytes:[]u8, max:?u32}, Table{entries:[]Value, max:?u32} — SHARED objects so grow (reassigns .bytes/.entries in place) visible to importers. deinit frees only DEFINED memory/tables + elem_values/dropped/tables outer/gc_heap outer, then arena.
initWithImports order: 1. Decode bodies→IR, precomputeControlFlow→end_of/else_of, local_defaults (ref→null_ref, num→0). 2. Globals: imported head (defined_start=globals.len-global_inits.len) from imports.globals; then eval defined inits via evalConstExpr(globals[0..defined_start+gi],expr). 3. Memory: imported(0) borrows imports.memories[0] (MissingImport); else alloc min*page_size zeroed heap Memory; copy active data segs (offset evalConstOffset, bounds→MemoryOutOfBounds). 4. Tables: n_imported borrow; defined alloc min entries=null_ref. 5. data_dropped=seg.active (active pre-applied). 6. Elements: alloc funcs.len+exprs.len; funcs→index, exprs→evalConstExpr; dropped=(mode!=.passive); active applied to tables[table_index] at evalConstOffset (bounds→TableOutOfBounds/NoTable).
FuncBody{type,num_locals,local_defaults:[]Value,ir:[]Instr,end_of:[]usize,else_of:[]usize}.
### B3 Control-flow: precomputeControlFlow single pass w/ opener stack. end_of[opener]=end_idx per block/loop/if; else_of[if]=else_idx (sentinel ir.len=no else); if-with-else end_of[else_idx]=end_idx. Trailing implicit fn end skipped.
Label{is_loop, arity:u32, target:usize, stack_base:usize} — arity=results (block/if) or params (loop); target=jump pc; stack_base=vstack height below operands.
branch(n) (load-bearing): label=labels[len-1-n]; move top arity values down to stack_base; shrinkRetainingCapacity(stack_base+arity); keep-count = len-n for loop (keeps own header) vs len-(n+1) forward exit; return label.target.
Block entry: block/if push {arity=results, target=end_of[pc]+1, stack_base=vstack.len-params}; loop push {is_loop, arity=params, target=pc+1, stack_base}. if: pop i32; true→pc+1; false→else_of[pc]+1 or (no else) end_of[pc]. else: jump end_of[pc]. end: pop label pc+1. return: pc=ir.len. br_table: index t.labels (bounds-checked signed) else t.default, then branch.
### B4 Frame + Frame.run + trap backtrace: Frame{inst,a,body,locals:[]Value,depth,func_index,vstack:ArrayList(Value),labels:ArrayList(Label)}. blockArity(bt,comptime want_params).
callFunction(a,func_index,args,depth): depth>max_call_depth(1024)→CallStackExhausted. func_index<imported_funcs → dispatch import_funcs. Else defined=func_index-imported_funcs; locals=local_defaults copy overwrite [0..args.len]; Frame seed one label {arity=results,target=ir.len,stack_base=0}; frame.run(); result=top results.len slots into fresh arena slice.
run = ~200-arm dispatch. Trap machinery: errdefer self.inst.recordTrap(self.func_index,pc) at top of run — fires only on error path, once per frame during unwind → innermost-first trace w/ zero plumbing. recordTrap is noinline — LOAD-BEARING (errdefer expands at every try across ~200 arms; inlining evicts loop from i-cache, ~14% measured twice). Rust: keep trap-record a single #[cold]/#[inline(never)] fn; naive ?-with-inline-append at each op reproduces the pathology.
recordTrap(func_index,pc): trap_depth+=1; if trap_len==max_trap_frames(16) return; else store, trap_len+=1. invokeIndex resets trap_len=trap_depth=0 per call. trapFrames()=[0..trap_len]; trapTruncated()=trap_depth>trap_len.
frameOffset(a,frame): IR-pc→byte offsets LAZILY by re-decoding one body with decodeBodyTracked, freeing IR. Returns {func, module=body_offset+in_func}. Not stored per-instruction (~7% cold-start + 4B/instr for rare path). Host-func frames (func_index<imported_funcs)→null.
TrapFrame{func_index:u32 (incl imports), pc:usize (IR index NOT byte offset)}.
### B5 Numeric/float/memory: run else→execNumeric→(else)execFloat. Memory→execMemory. Int bin/cmp applyInt(S,U,op,a,b), cmpI32/64. Traps: div/rem b==0→DivByZero; div_s minInt/-1→IntOverflow; rem_s b==-1→0. Shifts mask @mod(ub,bits). Rotl/rotr std.math. Floats fbin/fcmp: fmin/fmax NaN-propagate + ±0 via sign-bit OR/AND; rintEven round-half-even preserving zero sign (wasm nearest). Reinterpret = no-op. truncFloatS/U NaN/inf/OOR→InvalidConversionToInt; truncSatS/U NaN→0 clamp never trap. execMemory: memory.size=bytes.len/page_size; grow=memoryGrow (realloc shared .bytes, zero new pages, cap max orelse 65536, refuse→-1); load(T,ma)/store(T,ma,v): EA=base+ma.offset u64; ea+sizeof>len→MemoryOutOfBounds; LE readInt/writeInt; no mem→NoMemory.
### B6 Feature coverage in run: drop/select/select_t (select pops c,b,a→push c!=0?a:b, both forms identical runtime). Refs: ref_null→null_ref; ref_is_null; ref_func→push imm.func. i31: ref_i31=i31_tag|(x&0x7fff_ffff); i31_get_s sign-ext bit30 ((n<<1)>>1), _u mask 31 bits; both null→NullReference. ref_eq identity compare→i32. struct: struct_new packs fields in order, allocObject; _default null/0; get/set via gcObject (null→NullReference), field bounds→GcOutOfBounds, pack/unpack. array: array_new(len,init)/_default/_fixed(n from stack)/get/set (idx bounds→GcOutOfBounds)/len. casts: ref_test→i32 via refMatches; ref_cast peek top, refMatches else CastFailure, value stays; br_on_cast/_fail peek ref, branch iff match/¬match (ref stays both paths). call/call_indirect/call_ref: call pops params in place, calls, shrinks, push results. call_indirect: table bounds→NoTable, slot bounds→TableOutOfBounds, null_ref→UninitializedElement, funcTypeEqual else IndirectTypeMismatch. call_ref/return_call_ref: pop ref (null→NullReference); return_call_ref pc=ir.len (tail). ref_as_non_null (null→trap), br_on_null (null→branch drop ref; else keep+fall), br_on_non_null (non-null→keep+branch; null→consume+fall). Table ops get/set/size/grow(refuse→-1)/fill. Bulk mem memory_copy (overlap-safe fwd/bwd), fill, init (dropped→empty), data_drop. Table bulk table_init (dropped→empty), elem_drop, table_copy (overlap-safe). All bounds→MemoryOutOfBounds/TableOutOfBounds. Vars local_get/set/tee (tee peeks), global_get/set. start: runStart in scratch arena post-instantiate, trap=instantiation failure.
refMatches(v,rt): null→rt.nullable; else dispatch refHead(rt.heap).top(): .any→i31_tag set→headMatches(.i31), else heap object kind from comp_types[type_index].kind()→headMatches(kind,type_index,rt.heap); .func→headMatches(.func,definedFuncType(v)); else extern. headMatches: concrete target→actual_ti!=null && isSubtype(actual_ti,t); abstract→actual.sub(refHead(target)). definedFuncType(findex)→concrete type idx for defined, null for imports.
### B7 Host imports & linking: HostFunc=union: wasm{instance:*Instance,func_index:u32} — another module's export; call RUNS IN EXPORTING INSTANCE (w.instance.callFunction) = cross-module register. native:*const fn([]const Value,[]Value)void. native_env{ctx:*anyopaque, call:*const fn(ctx,args,results)bool} — host cb MAY trap (false→error.HostTrap); = C-ABI wasm_func_new. Imports{funcs,globals,memories,tables} align with per-kind import order (low indices). Imported funcs dispatch via import_funcs when idx<imported_funcs; globals filled at init head; memory/table borrow shared. MissingImport if declared import lacks backing (>import_funcs.len funcs→UnsupportedImportCall).
### B8 Trap taxonomy + exit codes: Error=Module.Error||{Unreachable,DivByZero,IntOverflow,CallStackExhausted,UndefinedExport,BadArgCount,UndefinedFunc,UnsupportedImportCall,MissingImport,UnsupportedInstruction,InvalidConversionToInt,MemoryOutOfBounds,NoMemory,UndefinedGlobal,NoTable,NullReference,TableOutOfBounds,UninitializedElement,IndirectTypeMismatch,UndefinedType,GcOutOfBounds,CastFailure,HostTrap}. NO dedicated exit-code channel — proc_exit/WASI exit carried THROUGH error.HostTrap (native_env cb stashes code in ctx, returns false; embedder reads code after catching).
### B9 evalConstExpr(globals,expr): [16]Value stack over i32/i64/f32/f64.const, global.get (into already-eval globals, bounds→UndefinedGlobal), ref.null→null_ref, ref.func→index, extended-const i32/i64 add/sub/mul (wrapping); end returns top. Overflow/bad→UnsupportedInstruction. evalConstOffset=asI32 result bitcast u32.

## Porting-critical invariants
1. Instance retains module:*const Module (UAF fix) — tie module lifetime to instance (Arc/borrow), don't free after instantiate.
2. recordTrap stays out-of-line (#[cold]/#[inline(never)]) — ~14% i-cache pathology otherwise.
3. Slot encoding: null=u64::MAX checked BEFORE i31_tag=1<<63; heap/func/extern all small-index. Three-way discrimination depends on ordering.
4. Shared *Memory/*Table so grow visible to importers — Rc<RefCell> / raw shared; growth reassigns backing slice in place.
5. branch() value-shuffle + label keep-count (loop keeps header) is the whole control-flow model; end_of/else_of precomputed once.
6. Byte offsets resolved lazily by re-decoding one body — don't store per-instruction offsets.
7. Validator subtyping: concrete-concrete via declared isSubtype, not collapsed heads; nullability one-directional.
8. Local-init: non-null ref locals uninit until set; snapshot/restore across if/else/end.
